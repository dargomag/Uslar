# Навык «Услар»

## Контекст проекта

Монография: П.К. Услар «Хюркилинский язык» (1892, 502 стр.)
Репозиторий: `https://github.com/dargomag/Uslar`
Структура репозитория:
- `raw/` — исходные тексты (дореволюционная орфография)
- `converted/` — конвертированные параграфы
- `urakhin-dictionary.txt` — урахинско-русский словарь
- `toponyms.txt` — топонимы и этнонимы

Уже обработаны: §§1–60.

## ВАЖНЫЕ ПРАВИЛА РАБОТЫ СО СЛОВАРЁМ

1. **Единственный источник истины** — файл словаря в репозитории:
   `https://github.com/dargomag/Uslar/blob/main/urakhin-dictionary.txt`
2. **Перед дополнением словаря** — всегда просить пользователя загрузить
   актуальную версию файла из GitHub в чат, либо использовать web_fetch
   для получения raw-версии файла.
3. **Никогда не дополнять** свои собственные старые версии словаря —
   только ту версию, которую загрузил пользователь из репозитория.
4. **Структура словаря**: разделы по урахинскому алфавиту с заглавными
   буквами заголовков (А, Б, В, Г, Гъ, Гь, Гl, Д, ...), статьи со
   строчных букв в формате:
   `* слово [часть речи, род] — перевод.`
5. **Топонимы и этнонимы** — вести отдельно, единственный источник:
   `https://github.com/dargomag/Uslar/blob/main/toponyms.txt`
   Перед дополнением — брать файл оттуда, никогда не использовать свои старые версии.

## Правила конвертации русского текста

> Принцип: менять **только орфографию**, не трогать слова и порядок слов.

1. Убрать **ъ** в конце слова (перед пробелом или знаком препинания)
2. Замены букв: ѣ→е, ѳ→ф, і→и, ѵ→и, ѡ→о, ѧ→я
3. Окончания: -ыя→-ые, -ія→-ие, -аго→-ого, -яго→-его
4. Предлоги: съ→с, въ→в, изъ→из, отъ→от, подъ→под, надъ→над, передъ→перед, объ→об
5. Числовые: во-1-хъ→во-первых, во-2-хъ→во-вторых, во-3-хъ→в-третьих

### Пример (эталон §59)
- Оригинал: `въ обоихъ языкахъ существуютъ одни лишь глаголы среднiе`
- Результат: `в обоих языках существуют одни лишь глаголы средние`

## Правила конвертации урахинских слов

Урахинские слова в тексте встречаются в латинско-кириллической транскрипции Услара.

### Важно: символ l (вертикальная палочка)

В урахинском алфавите существуют буквы, образованные сочетанием обычной
буквы с вертикальной палочкой: **гl, кl, пl, тl, хl, цl, чl**.
В текстах этого проекта вертикальная палочка обозначается английской
строчной **l** (эль).

**l — это не буква «л» и не латинский символ, это образ вертикальной
палочки.** Его нельзя переводить, транслитерировать или заменять.
Слова дукl, анкlи, хlу, тlвяхl и т.п. содержат именно этот знак.

### Таблица транслитерации (только для текстов Услара в старой записи)
| Услар | Современная |
|-------|-------------|
| q     | кь          |
| w     | в           |
| в     | б           |
| h     | гь          |
| i     | и           |
| j     | й           |
| ѣ     | е           |
| `     | ъ (смягчение) |

### Алгоритм обработки урахинского слова
1. Найти русский перевод слова в контексте
2. Поискать слово в словаре: `https://github.com/dargomag/Uslar/blob/main/urakhin-dictionary.txt`
3. **Найдено** → вставить современную форму из словаря
4. **Не найдено** → транслитерировать по таблице выше, пометить ⚠️

## Грамматика урахинского (для словарных статей)

## Рабочий процесс

### Задача 1: Конвертировать параграф

1. Получить текст параграфа (из `raw/` или от пользователя)
2. Применить все правила конвертации русского текста последовательно
3. Обработать каждое урахинское слово по алгоритму выше
4. Вернуть результат в формате:

```
§N (конвертировано)

[текст параграфа]

---
Новые урахинские слова (⚠️ требуют проверки):
- слово_услара → транслитерация [предполагаемый перевод]
```

### Задача 2: Пополнить словарь

После конвертации параграфа, если найдены новые урахинские слова:
1. Определить род по окончанию или контексту
2. Составить словарную статью по формату выше
3. Добавить в `https://github.com/dargomag/Uslar/blob/main/urakhin-dictionary.txt`

### Задача 3: Извлечь урахинские слова из §§1–60

1. Прочитать файл `raw/paragraphs-1-60.txt`
2. Найти все слова в транскрипции Услара (содержащие q, w, h, j, `, ѣ в сочетаниях, характерных для урахинского)
3. Для каждого слова: транслитерировать + найти перевод по контексту
4. Составить начальный словарь и сохранить в `https://github.com/dargomag/Uslar/blob/main/urakhin-dictionary.txt`

## Подсказки по краевым случаям

- **ъ внутри слова** (не на конце) — **не убирать**: `объяснить`, `подъём`
- **Предлог съ перед согласной** → `с`: `съ нимъ` → `с ним`
- **Предлог съ перед гласной** → `с` (не `со`, если не было в оригинале)
- **-аго как часть корня** (Углаго, Шаго и т.п.) — **не менять**; менять только окончания прилагательных
- **Урахинские имена собственные** — транслитерировать, не склонять, пометить ⚠️
- **Курсив/разрядка** в оригинале — сохранять разметку, если она есть в источнике
